대한민국 17개 시도 전체 시설을 확보/검증했다고 해석하면 안 된다.
추가 지역 수집이나 외부 주소 지오코딩은 이번 변경에 포함하지 않았다.

## 원인과 확인 한계

1. 현행 어린이집 수집기는 `la`/`lo`, 유치원 수집기는 `lttdcdnt`/`lngtcdnt`를
   숫자로 변환할 뿐 주소/행정구역과 비교하지 않았다. `parseFloat()`는 일부만
   숫자인 문자열도 허용하고 `|| 0`은 누락·파싱 실패를 0으로 숨겼다.
   같은 좌표가 여러 지역/주소에 반복돼도 탐지 과정이 없었다.
2. 현재 수집 코드에는 서울시청 좌표 대체 코드가 없고, git 이력의
   `55f2d98` 이후 어린이집 정규화도 API 좌표를 직접 읽는다. 과거의 무작위
   좌표 코드는 그 커밋에서 제거됐다. 그러나 저장된 JSON만으로는 그 이전
   생성물/외부 생성 경로까지 배제할 수 없다. 원본 API 응답·당시 로그와
   실행 가능한 API 키가 제공되지 않아 **서울시청 값이 원본 API에서 왔다고
   확정하지 않았다**. 원본 증거가 확보되기 전 이를 추정 좌표로 고치지 않는다.
3. 별도 확인된 수집 결함: `res.on('data', d => data += d)`는 네트워크 조각마다
   UTF-8을 디코딩한다. 한글 3바이트가 조각 경계에 걸리면 대체 문자 `�`가
   생길 수 있다. 바이트 단위 분할 테스트로 이를 재현하고 전체 Buffer를 합친
   후 한 번 디코딩하도록 수정했다. 과거 깨진 주소 모두의 발생 원인이 이것이라고
   단정하지 않으며 주소를 추측해 복원하지 않았다.
4. 목록의 기존 '위치 비슷함 순'은 위도/경도 오름차순이었다. 사용자/주소 기준점이
   없으므로 거리 기능을 가장하지 않고 **이름순(가나다)**으로 바꿨다.
   정원순은 내림차순이며 동률은 이름·기관 구분·ID로 안정적으로 정렬한다.

## 재발 방지와 운영

- API 정규화 시 숫자 전체 파싱, 유한값/한국 범위, 알려진 공통 대체 좌표,
  주소의 시도·시군구, 행정구역 폴리곤 및 파일 내 중복을 검사한다.
- 수집 완료 후 저장소 전체를 재검사해 파일/기관 유형 간 중복도 탐지한다.
- 정상 좌표로 판정하지 못하면 두 좌표를 `null`로 기록하고 카드에
  '위치 좌표 미확인'을 표시한다. 원본 좌표와 사유는 재감사 때도 유지한다.
- 경계 데이터는 SGIS 기반 admdongkor 2025-04-01 스냅샷이다.
  자세한 출처·라이선스·재생성 방법·경계 근처 오탐 가능성은
  [경계 데이터 안내](../scripts/geo/README.md)를 참고한다.
- `npm run audit:coordinates:fix`: 현재 데이터 재감사/수정과 상세 보고서 생성.
- `npm run audit:coordinates`: 데이터 계약 위반(미처리 이상 좌표/미분류 데이터)이
  있으면 종료 코드 1. 의도적으로 미확인 처리한 시설은 실패로 보지 않는다.
- `npm test`: 좌표 파싱·지역 불일치·3개 보고 시설·동일 건물 중복과 의심 중복·
  API 정규화·한글 분할 응답·재실행 불변성·정렬·전체 저장 데이터 회귀 검사.
- GitHub Actions에서 테스트, 전체 감사, TypeScript 및 정적 빌드를 실행한다.
  CI 빌드는 API 키 없이 감사된 저장 스냅샷을 사용한다.
- 전체 실시간 재수집은 키가 없어 실행하지 않았다. 기존 손상 주소는 다음 정상
  API 응답 또는 검증된 공식 주소 증거가 들어올 때 교체해야 한다.
